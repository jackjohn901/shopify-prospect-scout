# Shopify Prospect Scout

The complete source code is available in [shopify-prospect-scout-source.zip](shopify-prospect-scout-source.zip). It contains 126 files: the frontend, API, database migrations, tests, dependency lockfile and setup instructions.

## Use in Codex or OpenCode

1. Download and extract the source ZIP.
2. Open the extracted `shopify-prospect-scout` folder.
3. Read `START_HERE.md` for installation and local database setup.

The repository stores the source as a ZIP package. Extract it before running or editing the app.

## Features

Country research searches, prospect URL entry, sourced evidence, verification and freshness tracking, likely-need categories, buyer-intent scoring, public contact channels, filters, shortlist, prospect detail views, exports, and evidence-only outreach drafts.

## Validation

Ten automated tests, TypeScript checking, production build and desktop workflow QA passed. Hosted signed-in saving was not browser-tested.

No credentials or saved prospect records are included. The hosted prospect workspace remains private and sends no outreach.
